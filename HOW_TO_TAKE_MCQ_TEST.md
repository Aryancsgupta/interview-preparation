# MCQ Test कैसे दें - Step by Step Guide

## 📋 MCQ Test देने के Steps:

### Step 1: Login करें
- Website पर login करें
- अगर account नहीं है तो पहले register करें

### Step 2: Start Interview/Test पर जाएं
- Sidebar में "Start Interview" पर click करें

### Step 3: Test Settings Select करें
1. **Category**: अपना subject select करें
   - Frontend (React, JavaScript, CSS, etc.)
   - Backend (Node.js, Express, APIs, etc.)
   - General (Git, Programming concepts, etc.)

2. **Difficulty**: अपना level select करें
   - Easy
   - Medium
   - Hard

3. **Question Type**: यहाँ आप choose कर सकते हैं:
   - **"Only MCQ Questions"** - सिर्फ MCQ test के लिए
   - **"All Types"** - MCQ + Descriptive दोनों
   - **"Only Descriptive Questions"** - सिर्फ descriptive questions

4. **Number of Questions**: कितने questions चाहिए (जैसे 5, 10, 20)

5. **Topic**: Test का topic लिखें (जैसे "JavaScript Basics MCQ Test")

### Step 4: "Start Test" Button Click करें
- Button click करने के बाद questions load होंगे

### Step 5: MCQ Questions Answer करें
- **MCQ Questions** हरे रंग के box में दिखेंगे
- हर question के नीचे **multiple options** होंगे (A, B, C, D...)
- **Radio button** click करके सही option select करें
- हर question के लिए **सिर्फ एक option** select कर सकते हैं
- Option select करने पर वो highlight हो जाएगी

### Step 6: Descriptive Questions (अगर हैं)
- **Descriptive Questions** नीले रंग के box में दिखेंगे
- Textarea में detailed answer लिखें

### Step 7: Submit करें
- सभी questions answer करने के बाद
- **"Submit All Answers"** button click करें
- आपका score immediately show होगा

## 🎯 MCQ Test के Features:

✅ **Instant Results**: MCQ questions का result तुरंत मिलता है (100% या 0%)
✅ **Clear UI**: MCQ questions हरे box में, descriptive नीले box में
✅ **Easy Selection**: Radio buttons से आसानी से option select करें
✅ **Visual Feedback**: Selected option highlight होती है
✅ **Instructions**: हर test के साथ clear instructions दिए जाते हैं

## 💡 Tips:

1. **MCQ Only Test** के लिए "Only MCQ Questions" select करें
2. सभी questions answer करना जरूरी है
3. एक बार submit करने के बाद answers change नहीं कर सकते
4. Score immediately calculate होता है

## 📝 Example:

**MCQ Test Settings:**
- Category: Frontend
- Difficulty: Easy
- Question Type: Only MCQ Questions
- Number: 10
- Topic: JavaScript Basics MCQ

**Result:** 10 MCQ questions मिलेंगे जिन्हें आप radio buttons से answer करेंगे!
